Welcome to Heatmapper!

Heatmapper has been re-written in Python! This version brings new changes, including WebAssembly support, speed improvements, and more features. The old, R-Based Heatmapper is still available here. Checkout the Wiki for more information!

Click in the menu above or on the buttons below to start making your heat map!

Heatmapper is a freely available web server that allows users to interactively visualize their data through an easy-to-use graphical interface.
Heatmapper allows users to generate, cluster and visualize a wide variety of heat maps for many different data types and applications.
Heatmapper offers customization options for each heat map’s appearance and plotting parameters.
Heatmapper also allows users to interact with data via a searchable/sortable/editable data table view.

EXPRESSION
View data from your "omics" experiment as-is in a heatmap, or cluster it with dendrograms on rows and/or columns.

Supports .txt, .dat, .tsv, .tab, and .xlsx files.
PAIRWISE
Calculate a correlation or distance matrix, or display a pre-computed matrix as-is in a heatmap. Have 3 columns of data? Generate a cube matrix!

Supports .txt, .dat, .tsv, .tab, .xlsx, .pdb, and .fasta files.
IMAGE
Visualize an input table over an image. Data without column names is displayed as-is, while explicit X, Y, Z, and value columns are treated as coordinates.

Supports .bmp, .gif, .h5, .hdf, .ico, .jpeg, .jpg, .tif, .tiff, .webp, and .png files for images.
GEOMAP
Display values for defined territories on a map using GeoJSON files. Have temporal data? Scrub through time points with a media player-style slider.

Supports .txt, .dat, .tsv, .tab, and .xlsx files, plus .geojson for maps.
GEOCOORDINATE
Plot coordinates with associated values onto a map. Have temporal data? Scrub through time points with a media player-style slider.

Supports .txt, .dat, .tsv, .tab, and .xlsx files.
3D
Visualize data on the surface of a 3D object.

Supports:
an .obj file with either a table of values or image file to display on the surface, OR
a .pdb file or PDB ID.
SPATIAL
Display spatial molecular data, and generate plots of related metrics.

Supports Visium or NanoString collections of files.
Spatial heatmaps are run on the server.
SPECTRAL
Visualize mass spectrometry data as a 3D contour plot or a color matrix.

Supports .mzML files.
Spatial heatmaps are run on the server.
